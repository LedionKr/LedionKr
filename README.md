## Ausgewählte Projekte

### ♟️ Schachprojekt · C++17

Eine Konsolenanwendung mit **Standard- und Atomschach**. Die Implementierung umfasst Zugprüfung, Bauernumwandlung, den Import von Brettstellungen und die Rücknahme von Zügen. Brettzustand und Bewegungsprüfung sind getrennt aufgebaut; Google-Test-Tests mit mitgelieferten Datensätzen ergänzen den Code.

**Schwerpunkte:** Objektorientierung · STL · Spiellogik · Tests

[Projektüberblick & Startanleitung](https://github.com/LedionKr/Portfolio/blob/main/projects/schachprojekt/PORTFOLIO.md) · [Repository](https://github.com/LedionKr/schachprojekt)

Eine **fertige Website für Fahrzeugaufbereitung** mit Leistungspaketen, aufklappbaren FAQ und Kontaktwegen. Das Layout nutzt Flexbox, Grid und Media Queries.

**Schwerpunkte:** Webentwicklung · Responsive Layouts · Strukturierte Darstellung von Dienstleistungen

[Projektbeschreibung](https://github.com/LedionKr/Portfolio/blob/main/projects/AuraCleaning/README.md) · [Repository](https://github.com/LedionKr/AuraCleaning)
